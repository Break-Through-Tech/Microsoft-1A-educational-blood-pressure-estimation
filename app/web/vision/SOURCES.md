
# Face tracking files

- [MediaPipe Tasks Vision 0.10.21](https://www.npmjs.com/package/@mediapipe/tasks-vision/v/0.10.21) supplies the JavaScript and WebAssembly files.
- [BlazeFace short-range detector](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector/index#models) supplies the face model. The file comes from [Google's version 1 model URL](https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite).
- The included [Apache 2.0 license](./LICENSE) comes from MediaPipe's 0.10.21 source release.
